# Low-Level Design in Java

Java-based Low-Level Design (LLD) lessons focused on SOLID principles and core design patterns. This repository is organized as lesson-wise examples with practical, interview-oriented scenarios, including bad-vs-good implementations and runnable demos.

## Repository Overview

This repo contains:

- A study guide covering LLD fundamentals, SOLID principles, and common design patterns
- Lesson-wise Java files explaining each concept with examples
- Simple `main` methods in each lesson to demonstrate the design in action

## Lessons Covered

- Lesson 1: OOP Foundations and Single Responsibility Principle (SRP)
- Lesson 2: Open/Closed Principle (OCP) and Strategy Pattern
- Lesson 3: Liskov Substitution Principle (LSP) and Interface Segregation Principle (ISP)
- Lesson 4: Dependency Inversion Principle (DIP) and Dependency Injection
- Lesson 5: Factory Pattern and Builder Pattern
- Lesson 6: Observer Pattern and Decorator Pattern

## Files

- `lld-study-guide.md` - Conceptual notes and LLD reference material
- `Lesson1Main.java` - SRP and basic class design
- `Lesson2Main.java` - OCP and Strategy pattern
- `Lesson3Main.java` - LSP and ISP
- `Lesson4Main.java` - DIP and Dependency Injection
- `lld-lesson-5.java` - Factory and Builder patterns
- `lld-lesson-6.java` - Observer and Decorator patterns

## Purpose

This repository is intended for:

- Learning Low-Level Design step by step
- Practicing SOLID principles in Java
- Understanding commonly used design patterns
- Preparing for interviews involving OOP, LLD, and design patterns

## Notes

- The lessons are written as self-contained examples for learning.
- Some files are lesson-oriented and may need filename cleanup if you want strict Java compilation conventions for every file.
- The focus here is clarity of design concepts rather than production-ready project structure.
